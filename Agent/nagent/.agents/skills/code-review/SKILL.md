# Code Review Skill

## 使用场景
当用户请求代码审查、重构建议或 bug 分析时，使用此 Skill。

## 审查要点
1. **正确性**：逻辑是否正确，边界条件是否覆盖
2. **性能**：是否存在明显的性能问题（N+1 查询、全表扫描等）
3. **可维护性**：命名、函数长度、耦合度
4. **安全性**：SQL 注入、XSS、路径遍历

## 输出格式
对每个发现，给出：
- 严重程度（Critical / Warning / Suggestion）
- 具体位置
- 问题描述
- 建议修复方案
